# 3D clay icon concepts

Four original raster concepts generated with the built-in image_gen tool, saved for review.

- [DS Interlock](ds-clay-interlock.png): porcelain and lavender on indigo.
- [DS Sculpted](ds-clay-emboss.png): teal and terracotta on ivory.
- [Connected hub](clay-connected-hub.png): three interlocking clay links.
- [Clay chat](clay-chat-bubble.png): a lavender message bubble.

Open [preview.html](preview.html) to compare 96px, 48px and 32px sizes with rounded-square, circular and square masks.

The PNGs are opaque, square concept originals. Active application icons and configuration were not modified. Platform exports/adaptive layers can be prepared after a concept is selected.

The complete prompt set is saved in [prompts.md](prompts.md).
